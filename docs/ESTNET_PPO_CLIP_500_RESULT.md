# EstNet新版PPO-clip：500轮评估摘要

2026-09-07完成。协议`g1-estnet-ppo-clip-flat-v1`；4096环境，seed42随机初始化，24步采样，4epochs×4minibatches，固定学习率5e-4、clip0.2。开启自碰撞，仅hip yaw相对默认姿态额外限幅±20°，不做全腿soft-limit目标截断。

训练完整执行500轮、8000次Adam、2000次epoch KL测量，未回滚或跳过有限KL更新。第500轮检查点用seed43、32环境、每环境首个10秒回合评估，动作采用策略均值。

| 评估项 | 结果 |
|---|---:|
| 存活满10秒 | 32/32 |
| 通过当前工程步行门槛 | 0/32 |
| 平均前向速度 / 指令 | 0.06495 / 0.38426 m/s |
| 3D速度跟踪误差 | 0.35860 m/s |
| 有效交替落脚均值 | 0次/回合 |
| 双支撑 / 单支撑 | 73.24% / 25.21% |
| 接触足平均滑移速度 | 0.06043 m/s |
| 两脚均有>3cm脚踝高度起伏 | 0/32 |

这些结果支持“能保持平衡，尚未形成按指令正常交替行走”。有效落脚要求触地前腾空.08–.45秒；0次有效交替不等于双脚完全没有运动。高度起伏为出生1秒之后脚踝link的最大值减最小值，不是足底净空。此评估没有视频，不能判定脚尖方向或交叉腿是否解决。

首50轮与末50轮随机采样的平均reward为0.50583→0.53258，但平均前向速度为0.36278→−0.04178 m/s，速度误差0.53020→0.52524 m/s；reward小幅上升没有转化为确定性策略的步行。465次epoch KL高于旧0.02阈值，最高6.32221，全部更新仍执行；这排除了本次仍受旧KL回退跳步的情况，不足以把旧失败的原因全部归为KL。

训练与评估在测量保存之后有native−11退出异常；监督器记录为完成但关闭有警告，完整检查点与评估所用文件哈希已核对一致。检查点SHA256：`5636d2bc3c59a16c7701d5ac14eb1567a086673708e40afe9a48a94b380a70a5`。机器地址、GPU清单、进程记录和逐轮原始日志保留于本地。
